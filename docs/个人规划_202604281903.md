## 二、个人优势与不足

### 2.1 优势（面试中可以强化的点）

**1. 9年实战经验 + 全栈视野**
- 不是只会 CRUD，从需求分析到上线运维都有参与
- 做过 P2P 催收系统（复杂业务规则引擎）+ 电商全链路
- 有无管理头衔带队的经历（PMP 认证支撑）

**2. Spring 生态深度掌握**
- Spring Boot 自动配置原理、SPI 机制能讲清
- Spring Cloud 微服务（注册中心、配置中心、网关、熔断）实战
- Spring AI 能快速上手正是基于此优势——"Java 后端转 AI 应用开发"是最短的路径

**3. 务实工程能力**
- 从今天的踩坑记录看，定位问题的能力很强（依赖冲突、路径拼接、构造函数参数）
- 不排斥读源码、不惧怕新框架
- 有明确的"先理解原理再优化"的思维模式

**4. 认证背书**
- PMP 证明项目管理能力
- 软考中级证明系统设计能力
- 在中小企业面试中，这些是加分项

### 2.2 不足（需要正视和弥补的）

**1. 学历限制（硬伤）**
- 大专 + 自考本科，大厂简历关过不去
- **对策**：不投大厂，瞄准 SaaS/AI 创业公司、跨境电商技术团队（这类公司更看重能力）

**2. AI 领域零基础起步**
- 传统后端 → AI 应用转型，需要快速补齐概念
- **对策**：Spring AI 框架降低门槛，用 Java 生态的熟悉感来过渡

**3. 分布式/高并发场景不够硬**
- 做过分布式但没做过真正的高并发大流量
- **对策**：不需要刻意补，求职目标不是字节/阿里，中小企业不需要这个

**4. 简历包装能力**
- 长期在一家公司，项目经验可能不够丰富
- **对策**：spring-ai-demo 项目 + 踩坑记录包装成"AI 应用落地"经验
