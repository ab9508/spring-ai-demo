## 1. 冒泡排序（Bubble Sort）

### 排序逻辑

> 相邻两个元素比较，大的往后"冒"，每轮结束后最大元素沉底。

```
原始：[5, 3, 8, 4, 2]
第1轮：3 5 4 2 | 8  ← 8 冒到最后
第2轮：3 4 2 | 5 8  ← 5 沉底
第3轮：3 2 | 4 5 8
第4轮：2 | 3 4 5 8
结果：[2, 3, 4, 5, 8]
```

**核心思想**：每轮把当前未排序区的最大元素"冒"到末尾，像气泡上浮。

### Java 实现

```java
public void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {          // 外层：共 n-1 轮
        boolean swapped = false;                    // 优化：本轮无交换说明已有序
        for (int j = 0; j < n - 1 - i; j++) {   // 内层：比较相邻
            if (arr[j] > arr[j + 1]) {
                // 交换
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;                      // 提前结束
    }
}
```

### 关键点

| 维度 | 说明 |
|------|------|
| **时间复杂度** | 最好 O(n)（已有序）、平均 O(n²)、最坏 O(n²) |
| **空间复杂度** | O(1)（原地排序） |
| **稳定性** | ✅ 稳定（相等不交换） |
| **适用场景** | 数据量小（n < 1000）、几乎有序的数据 |

## 2. 选择排序（Selection Sort）

### 排序逻辑

> 每轮从未排序区选最小元素，放到已排序区末尾。

```
原始：[5, 3, 8, 4, 2]
第1轮：| 2 | 3 8 4 5   ← 选最小 2，放位置 0
第2轮：| 2 3 | 8 4 5   ← 选最小 3，放位置 1
第3轮：| 2 3 4 | 8 5
第4轮：| 2 3 4 5 | 8
结果：[2, 3, 4, 5, 8]
```

**核心思想**：每次选最小的，放到前面——"挑最小的往前放"。

### Java 实现

```java
public void selectionSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;                            // 假设当前位置是最小
        for (int j = i + 1; j < n; j++) {       // 向后找更小的
            if (arr[j] < arr[minIdx]) {
                minIdx = j;
            }
        }
        // 把最小的交换到位置 i
        if (minIdx != i) {
            int temp = arr[i];
            arr[i] = arr[minIdx];
            arr[minIdx] = temp;
        }
    }
}
```

### 关键点

| 维度 | 说明 |
|------|------|
| **时间复杂度** | 最好 O(n²)、平均 O(n²)、最坏 O(n²)（**无论数据是否有序都一样**） |
| **空间复杂度** | O(1) |
| **稳定性** | ❌ 不稳定（交换可能打乱相等元素顺序） |
| **适用场景** | 数据量小、不关心稳定性、交换成本高（如链表） |

## 3. 插入排序（Insertion Sort）

### 排序逻辑

> 从第二个元素开始，将当前元素插入到前面已排序区的正确位置。

```
原始：[5, 3, 8, 4, 2]
第1步：| 3 5 | 8 4 2   ← 3 插入到 5 前面
第2步：| 3 5 8 | 4 2   ← 8 已在正确位置
第3步：| 3 4 5 8 | 2   ← 4 插入到 5 前面
第4步：| 2 3 4 5 8 |   ← 2 插入到最前面
结果：[2, 3, 4, 5, 8]
```

**核心思想**：像整理扑克牌——拿到一张新牌，插入已有牌的正确位置。

### Java 实现

```java
public void insertionSort(int[] arr) {
    int n = arr.length;
    for (int i = 1; i < n; i++) {               // 从第 2 个开始
        int key = arr[i];                         // 当前要插入的元素
        int j = i - 1;
        // 向前找插入位置
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];                 // 元素后移
            j--;
        }
        arr[j + 1] = key;                        // 插入正确位置
    }
}
```

### 关键点

| 维度 | 说明 |
|------|------|
| **时间复杂度** | 最好 O(n)（已有序）、平均 O(n²)、最坏 O(n²) |
| **空间复杂度** | O(1) |
| **稳定性** | ✅ 稳定（相等不后移） |
| **适用场景** | **几乎有序的数据**（效率接近 O(n)）、小规模数据、链表排序 |

## 4. 快速排序（Quick Sort）

### 排序逻辑

> 选一个基准（pivot），小的放左边、大的放右边，递归处理左右子区间。

```
原始：[5, 3, 8, 4, 2]
选 pivot=5：
  → [3, 4, 2] 5 [8]     ← 左边 < 5，右边 > 5
递归左边 pivot=3：
  → [2] 3 [4]
合并：[2, 3, 4, 5, 8]
```

**核心思想**：分治法——"选一个基准，分成两堆，各堆再排"。

### Java 实现（原地版）

```java
public void quickSort(int[] arr, int left, int right) {
    if (left >= right) return;

    int pivot = arr[left];                         // 选最左为基准（可优化为三数取中）
    int i = left, j = right;

    while (i < j) {
        while (i < j && arr[j] >= pivot) j--;    // 从右找比 pivot 小的
        while (i < j && arr[i] <= pivot) i++;     // 从左找比 pivot 大的
        if (i < j) {
            int temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;
        }
    }
    // i==j 时，把 pivot 放到正确位置
    arr[left] = arr[i];
    arr[i] = pivot;

    quickSort(arr, left, i - 1);                  // 递归左半
    quickSort(arr, i + 1, right);                 // 递归右半
}
```

### 关键点

| 维度 | 说明 |
|------|------|
| **时间复杂度** | 最好 O(n log n)、平均 O(n log n)、最坏 O(n²)（已有序 + pivot 选最差） |
| **空间复杂度** | O(log n)（递归栈，最坏 O(n)） |
| **稳定性** | ❌ 不稳定（partition 过程打乱顺序） |
| **适用场景** | **通用排序首选**、大规模随机数据、内存受限（原地） |

## 5. 归并排序（Merge Sort）

### 排序逻辑

> 把数组拆成两半，分别排序，再合并两个有序数组。

```
原始：[5, 3, 8, 4, 2]
拆分：[5,3,8] [4,2]
拆分：[5] [3,8] | [4] [2]
拆分：[5] [3] [8] | [4] [2]
合并：[3,5] [8] | [2,4]
合并：[3,5,8] | [2,4]
合并：[2,3,4,5,8]
```

**核心思想**：分治法——"先分后合，合并时双指针"。

### Java 实现

```java
private int[] temp;  // 临时数组，避免频繁创建

public void mergeSort(int[] arr) {
    temp = new int[arr.length];
    mergeSort(arr, 0, arr.length - 1);
}

private void mergeSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);
    merge(arr, left, mid, right);
}

private void merge(int[] arr, int left, int mid, int right) {
    // 复制到临时数组
    for (int i = left; i <= right; i++) {
        temp[i] = arr[i];
    }
    int i = left, j = mid + 1, k = left;
    while (i <= mid && j <= right) {
        arr[k++] = temp[i] <= temp[j] ? temp[i++] : temp[j++];
    }
    while (i <= mid) arr[k++] = temp[i++];
    while (j <= right) arr[k++] = temp[j++];
}
```

### 关键点

| 维度 | 说明 |
|------|------|
| **时间复杂度** | 最好 O(n log n)、平均 O(n log n)、最坏 O(n log n)（**稳定 O(n log n)**） |
| **空间复杂度** | O(n)（临时数组） |
| **稳定性** | ✅ 稳定（merge 时 `<=` 保证相等顺序） |
| **适用场景** | 大规模数据、**需要稳定排序**、链表排序、外部排序（磁盘） |

## 6. 五大排序算法对比表

### 选型决策树（面试速答）

```
数据规模？
├── 小规模（n < 50）→ 插入排序（几乎有序时最快）
├── 中等规模（n < 10⁴）→ 插入 / 快速排序均可
└── 大规模（n ≥ 10⁴）→
    ├── 需要稳定？→ 归并排序
    └── 不需要稳定？→ 快速排序（工程首选）
```

## 7. 面试速记口诀

> **五句话记住核心差异：**

1. **冒泡**：相邻比大小，大的往后冒，**稳定 O(n²)**，适合小数据
2. **选择**：每轮挑最小放前面，**不稳定 O(n²)**，交换次数少
3. **插入**：像插扑克牌，**稳定 O(n²)**，几乎有序时最接近 O(n)
4. **快速**：分治基准，左右递归，**不稳定 O(n log n)**，工程最常用
5. **归并**：先分后合双指针，**稳定 O(n log n)**，外部排序/链表首选
