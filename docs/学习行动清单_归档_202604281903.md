## 未完成任务

### RAG 参数调优（优先级 P0，影响回答准确度）

**现状**：`TokenTextSplitter` 使用默认参数，回答效果不佳。

**优化内容**：

```java
// 1. TokenTextSplitter 参数调整（RagService.java）
TokenTextSplitter splitter = new TokenTextSplitter(
    300,     // chunkSize：默认800太大，中文场景300更合适
    50,      // minChunkSizeChars
    5,       // minChunkLengthToEmbed
    10000,   // maxNumChunks
    true     // keepSeparator
);

// 2. SearchRequest 加相似度阈值（RagController.java）
SearchRequest.builder()
    .query(question)
    .topK(5)
    .similarityThreshold(0.7)   // 过滤噪音片段
    .build();
```

**详细分析**：见 `踩坑记录_202604281750.md` → TODO-1

### ChatMemory 多轮对话记忆（优先级 P0）

**现状**：每次对话请求独立，AI 无法理解上下文（"到哪了？" 无法关联上一句的订单）。

**目标**：通过 `InMemoryChatMemory` 实现多轮对话记忆。

**实现要点**：
- 创建 `InMemoryChatMemory` Bean
- 每次 `prompt()` 前加载历史消息
- 每次响应后保存到 memory
- `conversationId` 区分不同用户

**详细概念**：见 `SpringAI知识积累_20260426.md` → 第七章
